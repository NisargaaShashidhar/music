# LocalBeats

Offline music player for Android (Kotlin, no third-party libraries).

Features: local music from your phone, playlists, background playback with a notification,
per-song artwork from your gallery, custom app background (with dark overlay), and a home-screen
shortcut using your own photo.

## Get the APK (no Android Studio needed)
1. Create a free account at github.com and make a new repository (e.g. `LocalBeats`).
2. Upload everything in this folder (drag the files and the `.github`, `app` folders onto the repo page).
3. Open the repo's **Actions** tab -> **Build LocalBeats APK** -> wait ~3-5 minutes.
4. Open the finished run, download **LocalBeats-apk** (zip), unzip -> `app-debug.apk`.
5. Send it to your phone, tap it, allow "Install unknown apps" when asked.

## Using it
- Tap a song to play. Long-press a song: set artwork, add to playlist.
- Playlists tab: tap + to create; long-press a playlist to delete.
- Menu (the three dots): background photo, home-screen shortcut, rescan music.
